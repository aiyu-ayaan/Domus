# Brag Plan: Domus
Self-hosted home automation (Rust backend, React web, Electron desktop, native Android) for Tuya, Tapo and Xiaomi devices.
Angle: a quiet, premium product film. It opens on the real Android splash (three modules scale in 90 ms apart, the last turns `on` green, using the app's own fast_out_slow_in curve), then shows the working app.
Tone: polished / cinematic restraint. Format: vertical 9:16, 1440x2560. Duration: 24 s.
Storyboard: A splash 0-3 | B "Your whole home, one app." + Tuya/Tapo/Xiaomi chips 3-6.5 | C Android home then devices 6.5-10.5 | D "Automate it. Measure it." scenes + energy 10.5-15 | E "Everywhere you are." desktop + web + Android 15-20 | F Domus lockup, "Your home, on your server.", "Now in alpha" 20-24.
Palette: #09090B / #FAFAFA / on-green #22C55E, Inter. Music: bundled happy-beats vol-1 (120 BPM), reveals on its beat grid; soft Kenney SFX. No audio-reactive layer.
Data: all screens come from a throwaway demo server with fictional devices, rooms, user and energy history. No real data on screen.
